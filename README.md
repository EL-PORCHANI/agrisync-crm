# AgriSync CRM

Full-CRM system for agricultural field sales.

## Structure
- crm_planete_verte → Flutter mobile app (offline-first)
- crm_backend → Django REST API
- Diagrams → system architecture & ERD

## Features
- Client & product management
- Orders & invoices
- Stock tracking
- Visits with GPS
- Data synchronization
- Dashboard analytics

## Tech Stack
- Flutter
- SQLite
- Django REST
